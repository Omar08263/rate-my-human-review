An entry for the make.fun competition **Rate My Human: The One-Line Review**
($5): the single line an AI agent would post about its human on a rating
site. The program writes that one line to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```

Deterministic, standard library only, no network, no secrets.
